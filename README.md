# SHUBIR RACING

An offline Android landscape endless highway racing game prototype built with Godot 4.

## Planned features
- Third-person chase camera and endless highway
- Blue and red selectable cars with custom `SUBHOJIT` / `BIRAJ` decals
- Touch steering, brake, accelerator and nitro controls
- Traffic, collisions, sounds, score and garage

## Project status
Starter project setup. Gameplay and Android export still need implementation and testing in Godot 4 Android Editor.

## Visual theme
Orange accent: `#FF7518`.
